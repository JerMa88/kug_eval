# kug_eval
kug-eval—a lightweight, dataset-agnostic, plug-and-play Python package.  It takes ANY dataset and ANY fine-tuned model checkpoint(s), evaluate the Memorization Accuracy ($A_{\text{mem}}$) and Generalization Accuracy ($A_{\text{gen}}$) curves across training epochs, and output a complete Knowing-Using Gap (KUG) diagnostic report.
